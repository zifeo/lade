name: silcrow
description: Runs `silcrow agent` immediately and follows that output. Use when the repository follows Silcrow, when editing laws or markers, or when the Silcrow index is stale or out of context.
---

Run `silcrow agent` immediately. Follow that output strictly.

Then run `silcrow agent <topic>` for the chosen topic.

If the index is stale, forgotten, or out of context, run `silcrow agent` again. Do not reconstruct it from memory.

If `silcrow agent` is missing, install it from https://github.com/zifeo/silcrow.
